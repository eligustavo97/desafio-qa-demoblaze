# Projeto de Automação QA — Desafio Técnico

Projeto de automação de testes cobrindo testes de API e testes E2E/UI para o e-commerce [DemoBlaze](https://www.demoblaze.com).

## 🚀 Tecnologias Utilizadas

- **Cypress v13+** (Automação E2E / UI)
- **Cucumber / Gherkin** (`@badeball/cypress-cucumber-preprocessor` para BDD)
- **Page Object Model (POM)**
- **Webpack** (Preprocessador de módulos)
- **Postman & Newman** (Testes de API e execução via CLI)
- **Node.js**

## 📋 Pré-requisitos

- **Node.js**: v18.0.0 ou superior
- **npm**: v9.0.0 ou superior
- **Git**
